# Contributing to ManuView

Thank you for your interest in contributing to **ManuView**!  
Our mission is to make pre-submission scientific peer-review diagnostics free, open-source, and accessible to researchers and students worldwide.

---

## 🛠️ Ways to Contribute

1. **Review Rubrics & Scientific Calibration**: Help refine the diagnostic prompts and rubrics based on real editorial guidelines and peer-review standards across disciplines (Biomedicine, Computer Science, Economics, Physical Sciences, etc.).
2. **Bibliographic & Integrity Checks**: Enhance reference parser accuracy, Crossref/OpenAlex/PubMed integrations, and retraction detectors.
3. **Frontend & UX**: Build intuitive, clean, academic-focused user interfaces, flowcharts, and dashboards.
4. **Local AI & Privacy**: Improve local model support (Ollama, vLLM, quantized models) for 100% offline, privacy-first manuscript analysis.
5. **Documentation & Testing**: Add test manuscripts, unit tests, and guides for researchers.

---

## 🚀 Development Workflow

1. **Fork the repository** on GitHub.
2. **Clone your fork**:
   ```bash
   git clone https://github.com/<your-username>/manuview.git
   cd manuview
   ```
3. **Create a feature branch**:
   ```bash
   git checkout -b feature/my-new-feature
   ```
4. **Make your changes and test thoroughly**.
5. **Commit your changes**:
   ```bash
   git commit -m "feat: add citation claim verification logic"
   ```
6. **Push to your branch**:
   ```bash
   git push origin feature/my-new-feature
   ```
7. **Open a Pull Request** with a clear explanation of what changed.

---

## 💡 Code of Conduct

ManuView is dedicated to providing a respectful, inclusive, and collaborative environment for everyone, regardless of background, gender, or academic discipline. Please be kind, constructive, and rigorous in reviews.
